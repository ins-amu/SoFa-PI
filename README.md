# SoFa-PI

Codebase for the paper "Probing other’s Presence: Probabilistic Inference Across Brain Scales Reveals Enhanced Excitatory Synaptic Efficacy"

![Scheme of the analysis](./Figs/SoFa_Summary.svg)

## Dependencies
The main dependencies for running the code are:

* Simulation-based inference (sbi)
* Numpyro
* Xarray
* Numpy
* Scipy
* Scikit-learn
* Matplotlib
 
## Experimental data
* Access to the computed simulations or synthetic/empirical features for running the code is available upon reasonable request. Empirical data from the tasks is available on Zenodo https://doi.org/10.5281/zenodo.16487740.

## Reference

* Esmaeili, A., Demolliens, M., Viersen, M., Ziaeemehr, A., Isbaine, F., Huguet, P., ... & Hashemi, M. (2025). Probabilistic inference of social presence across brain scales reveals enhanced synaptic efficacy. Communications Biology, 8(1), 1608. https://doi.org/10.1038/s42003-025-08971-3
